# Kaggle Projects

This repository contains a collection of Kaggle and machine-learning projects that I have worked on while developing my skills in data science, machine learning, and deep learning.

The projects are organized as Jupyter notebooks and focus primarily on image-classification problems.

## Projects

| Notebook | Description |
|---|---|
| [`chest-xrays-neural-network.ipynb`](chest-xrays-neural-network.ipynb) | Neural-network experiments using chest X-ray images. |
| [`digit-recognizer.ipynb`](digit-recognizer.ipynb) | A digit-recognition project exploring image classification of handwritten digits. |
| [`picture-identifier.ipynb`](picture-identifier.ipynb) | An image-identification project exploring neural-network-based image classification. |

## Project Goals

These projects were completed as hands-on exercises to practice the end-to-end machine-learning workflow, including:

- Loading and exploring image data
- Data preprocessing
- Building and training classification models
- Evaluating model performance
- Experimenting with neural-network approaches
- Working with Jupyter notebooks and Python-based data-science tools

## Purpose

This repository serves as a record of my earlier machine-learning projects and my progression in applying neural networks to image-classification problems. For more recent end-to-end data-science and deep-learning projects, see my other repositories on GitHub.
